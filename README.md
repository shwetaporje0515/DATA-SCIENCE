# DATA-SCIENCE

## Data-Science :
    -Data Science is the process of collecting, understanding, and analyzing data to find useful information and solve problems. It helps people and businesses make better decisions based on facts instead of      guessing.
    -Data Science is the study of data to find useful information and make better decisions.

## Tools Used :
    * Python
    * SQL
    * Excel
    * Pandas
    * NumPy
    * Power BI
    * Tableau
